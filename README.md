# PUMP/USDT live chart

Phone-friendly TradingView-style chart for PUMP/USDT.

- **[Tokocrypto version](https://dedkovic441-hub.github.io/coin-chart/)** (default) — use this if Binance is blocked
- **[Binance Spot version](https://dedkovic441-hub.github.io/coin-chart/binance.html)**

Charts use Lightweight Charts, REST history, and a live WebSocket (aggTrade + kline). Times are UTC+7.
